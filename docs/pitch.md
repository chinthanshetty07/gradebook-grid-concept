# Prototype pitch (for an application form or email)

I built an independent concept, a keyboard-first gradebook grid in React and Redux, after reading Toddle's frontend
posting and public gradebook page. It stays instant on a 61,000-cell class (about 18 ms from keypress to painted
versus about 1.9 s without virtualization) and supports spreadsheet paste, undo and an accessible grid, with 35 tests
and CI. It uses synthetic data and is not an official Toddle project; the README explains the measurements and limits.
